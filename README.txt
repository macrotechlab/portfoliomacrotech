LANDING PAGE — SUAMARCA

Arquivos:
- index.html: conteúdo da página e metadados.
- styles.css: layout, cores, tipografia e responsividade.
- script.js: menu para celular, links do WhatsApp e ano automático.

COMO PERSONALIZAR
1. Abra index.html e substitua “SuaMarca” e os textos de exemplo pelos dados do seu negócio.
2. Abra script.js e substitua WHATSAPP_PHONE pelo número real, usando código do país + DDD + número, sem espaços, parênteses ou sinais.
   Exemplo: 5511999999999 (Brasil + DDD 11 + telefone).
3. Personalize WHATSAPP_MESSAGE com a mensagem que deseja receber.
4. Para visualizar, abra index.html em um navegador. Não precisa instalar dependências.
5. Para publicar, envie os três arquivos juntos para seu serviço de hospedagem estática.

Observação: o telefone inicial é apenas um exemplo fictício; troque-o antes de divulgar o site. A página não envia dados para servidores nem usa bibliotecas externas. A fonte pode carregar do Google Fonts; se não carregar, serão usadas fontes locais alternativas.
